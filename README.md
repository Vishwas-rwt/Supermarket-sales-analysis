# SuperMart Sales Analysis & Reporting 📊

## Project Overview
This project involves the end-to-end data processing, validation, and analysis of approximately 1,000 retail sales records for a fictional supermarket chain. The goal of this project is to translate raw, unstructured sales data into clear, actionable business reporting. 

It demonstrates core data operations skills, including revenue reconciliation, error identification, structured filtering, and data visualization using Microsoft Excel.

## Key Objectives
*   **Revenue Reconciliation:** Validated data accuracy by comparing Gross Amount, Net Sales, and Discount Amounts across all transactions to identify discrepancies.
*   **Performance Tracking:** Evaluated sales representative performance and regional sales volume to determine top-performing areas.
*   **Trend Analysis:** Analyzed the impact of city-level discounts and payment modes on overall revenue and customer purchasing behavior.
*   **Data Visualization:** Built dynamic reporting views to allow stakeholders to quickly consume complex monthly trends and customer segment data.

## Tools & Techniques
*   **Tool:** Microsoft Excel
*   **Techniques:** 
    *   Data Validation & Quality Checks
    *   PivotTables & PivotCharts
    *   Advanced Sorting, Filtering, and Conditional Formatting
    *   Financial Reconciliation Logic

## Dataset Details
The dataset contains roughly 998 sales records, encompassing the following key variables:
*   **Geographic:** Region, City
*   **Product & Customer:** Product Categories, Customer Types
*   **Financials:** Gross Amount, Discount Amount, Net Sales, Payment Modes
*   **Operations:** Sales Representatives, Order Volume

## Project Structure
*   `SuperMart_Sales_Analysis.xlsx` - The primary workbook containing:
    *   **Raw Data:** The unformatted, raw sales dataset.
    *   **Finance Recon:** Reconciliation views ensuring financial data integrity.
    *   **Sales Report:** PivotTables detailing category, regional, and monthly sales trends.
    *   **Rep Performance:** Visualized metrics tracking individual sales representative success.

## How to View
1. Clone this repository or download the `.xlsx` file directly.
2. Open the file in Microsoft Excel (version 2016 or newer recommended for full PivotChart functionality).
3. Navigate through the worksheet tabs to view the raw data, reconciliation logic, and final reporting dashboards.
